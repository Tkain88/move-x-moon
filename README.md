## Local Development

To run the application locally:

```bash
python3 -m http.server 8088 --directory "Move x Moon"
```

Open your browser to [http://127.0.0.1:8088](http://127.0.0.1:8088).

To run validation checks:

```bash
python3 tools/build_site.py
```
