# Moon Ritual Transcripts

Five unique recordings were transcribed. Duplicate video and audio versions of the same activations were not transcribed twice.

## Recordings

- Full Moon Activation
- New Moon Activation
- Waning Moon Activation
- Waxing Moon Activation
- Moon Meditation

## Formats

Each transcript is supplied in five formats:

- `.txt` for straightforward reading and editing
- `.srt` for timestamped subtitles
- `.vtt` for web-video captions
- `.tsv` for timestamped tabular data
- `.json` for structured transcript data with word-level timing

The transcripts were generated with Whisper Large V3 Turbo. A second transcription pass used silence and hallucination controls to remove repeated phrases falsely generated during quiet meditation passages. As with any automated transcript, unusual terminology may still benefit from a final human proofread against the recordings.
